# claude/

Everything specific to Claude Code (CLI, IDE extensions, Agent SDK, API).

- `setup/` — install steps for CLI, IDE plugins, MCP servers, authentication.
- `tools/` — notes on built-in tools, skills, and subagents.
- `config/` — `settings.json`, `CLAUDE.md`, and hook templates.
- `slash-commands/` — custom commands worth reusing.
- `workflows/` — Claude-flavored versions of the patterns in `shared/workflows/`.
