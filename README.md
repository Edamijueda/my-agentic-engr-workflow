# my-agentic-engr-workflow

Personal playbook for working efficiently with coding agents. When starting a new project, come here first to prepare the machine and the repo.

## Layout

- `shared/` — agent-agnostic principles, project-setup checklists, and workflows that hold across any coding agent.
- `claude/` — Claude Code specifics: install, tools, config, slash commands, workflows.
- `research/` — raw notes from exploring Anthropic docs and GitHub repos before they get distilled into `shared/` or `claude/`.

Add a new top-level dir per coding agent as needed (e.g. `cursor/`, `aider/`). Promote anything cross-cutting into `shared/`.
